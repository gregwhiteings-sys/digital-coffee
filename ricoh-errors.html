Paper Jams & Service
SC302
Cause: Polygon motor error — Laser scanner motor not reaching operating speed.
✅ Solution:
1. Power OFF → Wait a few minutes → Power ON
2. Check laser unit connection and flat cable
3. Clean laser glass window — dust blocks beam
4. Check cooling fan near laser unit
5. If persists → Replace polygon motor or laser unit
SC320
Cause: Laser beam detection error — LD (Laser Diode) malfunction.
✅ Solution:
1. Power cycle machine
2. Check laser unit connector is fully seated
3. Check for obstruction in laser path
4. Replace laser diode unit if persistent
SC340
Cause: Scanner home position sensor error — exposure lamp not finding home.
✅ Solution:
1. Open and close scanner glass cover
2. Clean scanner glass and white reference plate
3. Check scanner cable (flat flex cable) at both ends
4. Check scanner lamp operation
5. Lubricate scanner rail sparingly
SC400
Cause: Drum charge corona error — abnormal charging current detected.
✅ Solution:
1. Power OFF → Remove drum unit
2. Clean corona wire or grid — use cleaning brush
3. Check corona unit connector and high-voltage contacts
4. Check drum surface for scratches or damage
5. Replace corona assembly or drum unit as needed
SC401
Cause: Transfer current error — primary transfer roller/bias malfunction.
✅ Solution:
1. Remove transfer belt/roller unit
2. Clean transfer roller contacts — avoid touching with bare hands
3. Check high-voltage power supply harness
4. Replace transfer roller/belt if worn or damaged
SC411
Cause: Development bias error — abnormal voltage to developer unit.
✅ Solution:
1. Remove developer unit → check connector pins
2. Check developer material level and condition
3. Clean developer unit sensor contacts
4. Check high-voltage power supply board
5. Replace developer if counter is expired
SC440
Cause: Drum motor lock error — drum unit not rotating at correct speed.
✅ Solution:
1. Power OFF → Remove drum unit
2. Check drum is not locked or jammed — rotate by hand gently
3. Check drive gears and couplings for damage
4. Check drum motor connector
5. Replace drum motor or drive gear assembly
SC542
Cause: Fuser temperature not rising — warm-up failure. The most common Ricoh error code!
✅ Solution — ⚠️ CAUTION: Fuser gets HOT! Cool down first:
1. Power OFF → Wait 10–15 minutes to cool
2. Check fuser unit is fully inserted and locked
3. Check fuser power connector — reseat firmly
4. ⚠️ Reset the code: Enter Service Mode → Mode → 5 → # → 810 → Execute → Yes/On
5. If returns immediately → Check thermistor, thermofuse, or heater lamp/element
6. Replace fuser unit parts as needed
SC541
Cause: Fuser temperature too low during standby / initial warm-up.
✅ Solution:
1. Same as SC542 — cool down first
2. Check power supply voltage is stable — use surge protector
3. Check fuser heater lamp continuity
4. Check thermistor contact against roller
5. Reset in Service Mode — Function 5-810
⚠️ If code returns → Do NOT keep resetting — risk of fire! Replace fuser parts.
SC543
Cause: Fuser overheat detected — temperature exceeded safe limit.
✅ Solution — ⚠️ SAFETY FIRST — let cool completely:
1. Power OFF immediately — do NOT keep running
2. Wait 20–30 minutes to cool down fully
3. Check ventilation slots — clear all dust and obstructions
4. Check fuser cooling fan is working
5. Clean thermistor — buildup causes false readings
6. Reset in Service Mode after cooling
⚠️ Critical fault — if recurs, replace fuser unit!
SC550
Cause: Pressure roller temperature sensor error (colour machines often).
✅ Solution:
1. Power OFF → Remove fuser unit
2. Check pressure roller thermistor wiring
3. Clean sensor contact point
4. Check pressure roller is not damaged
5. Reinstall → Reset → Power ON
SC620
Cause: Communication error between main controller and engine board.
✅ Solution:
1. Power OFF → Unplug from wall → Wait 5 minutes → Restart
2. Check all flat cables and connectors between boards — reseat
3. Check for bent pins or damaged connectors
4. Update firmware if possible
5. Replace controller board or engine board as last resort
SC670
Cause: Controller startup error — machine control board not booting correctly.
✅ Solution:
1. Power OFF → Unplug → Wait 5 minutes → Restart
2. Check power source is clean and stable
3. Remove and reinsert memory chips/SD card if accessible
4. Check firmware SD card — reflash if needed
5. Replace controller board if hardware failure
SC681
Cause: Network board / interface error — internal network card malfunction.
✅ Solution:
1. Power cycle machine
2. Disconnect network cable → Power ON without cable
3. Check network board connection — reseat
4. Reset network settings to default
5. Replace network board if hardware fault
SC720
Cause: Toner bottle motor error — toner supply bottle not rotating.
✅ Solution:
1. Remove toner bottle → check for blockage
2. Shake toner bottle gently to redistribute toner
3. Check bottle drive gear — not stripped or jammed
4. Check toner supply port for hardened toner
5. Reinstall bottle firmly → Power cycle
SC722
Cause: Toner density sensor error — developer unit not detecting correct toner ratio.
✅ Solution:
1. Enter Service Mode → Check developer counter
2. Remove developer unit → clean ID sensor with dry cloth
3. Check developer material level and condition
4. Run auto toner calibration
5. Replace developer unit if counter expired
SC726
Cause: Drum unit recognition error — chip or communication fault.
✅ Solution:
1. Remove drum unit → clean the contact chip with dry cloth
2. Check drum unit connector pins inside machine
3. Reinstall drum firmly → Power cycle
4. Replace drum chip or entire drum unit
5. Enter correct region code if recently moved
SC792
Cause: Waste toner bottle full or sensor error.
✅ Solution:
1. Remove waste toner bottle — empty carefully (do NOT inhale toner dust)
2. Clean bottle sensor window and sensor inside machine
3. Reinstall empty bottle → Reset counter if required
4. If new bottle still shows error → Replace sensor or bottle
SC819
Cause: Hard disk drive error — read/write failure or bad sectors.
✅ Solution:
1. Power cycle machine
2. Enter Service Mode → Format HDD
3. Note: All stored jobs, address book, settings will be erased
4. If formatting fails → Replace HDD
5. Restore firmware and settings after HDD replacement
SC820
Cause: Software / firmware error — program crash or corrupted data.
✅ Solution:
1. Power OFF → Wait 2 minutes → Power ON
2. Update/reflash firmware from SD card
3. Check SD card for corruption
4. Replace controller board if persistent
Paper Jam Codes (Jxxx)
Cause: Paper misfeed — indicated by location code (tray 1/2/3, feed, transport, fuser, exit).
✅ Solution — General Jam Clearing:
1. Follow on-screen LED indicators — open correct doors/panels
2. Remove paper GENTLY — tearing leaves scraps that repeat jam
3. Check BOTH sides of paper path — upper AND lower
4. Check paper size setting matches loaded paper
5. Use good quality dry paper — damp paper causes constant jams
6. Clean feed and separation rollers — alcohol wipe or replace if shiny/worn
🔧 Service Mode Access
Purpose: Reset fuser errors (SC542), view counters, calibrate, change settings.
✅ How to Enter Service Mode (Most Ricoh models):
1. Press: Clear Modes (yellow button)
2. Press: 1 → 0 → 7
3. Hold down: Clear / Stop (red button) for about 5 seconds until screen changes
4. Navigate: System Settings or Maintenance menu
5. To reset SC542: Select Mode 5 → # → 810 → Execute / On
⚠️ Don't change settings you don't understand — can damage machine!
